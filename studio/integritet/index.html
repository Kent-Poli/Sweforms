Integritet och webbstatistik

När du kontaktar oss

När du mejlar SweForms Studio tar vi emot din e-postadress och de uppgifter du lämnar i meddelandet. Vi använder uppgifterna för att svara och följa upp ditt ärende.

Webbstatistik

Vi använder Cloudflare Web Analytics för att se hur webbplatsen används, till exempel vilka sidor som visas och hur snabbt de laddas. Cloudflare Web Analytics använder inga kakor för den här mätningen.
