Integritetspolicy

Senast uppdaterad: 25 november 2026

Din trygghet är viktig för oss. Här beskriver vi vilka personuppgifter SweForms Studio hanterar när du besöker butiken, kontaktar oss eller gör en beställning, varför de behövs och hur vi skyddar dem.

1. Vem ansvarar för dina uppgifter?

SweForms, som drivs av Kent Poli i Sverige, ansvarar för den behandling av personuppgifter som vi själva bestämmer över.

Kontakta oss på kontakt@sweforms.se eller 073-822 40 40.

2. Vilka uppgifter samlar vi in och varför?

  • Beställningar: namn, e-postadress, leverans- och eventuella faktureringsuppgifter, beställda varor, belopp, orderreferens och betalningsstatus. Telefonnummer behandlas om det lämnas eller behövs för leverans eller kontakt. Uppgifterna används för att hantera köp, betalning, orderbekräftelse, leverans och returer. Rättslig grund: fullgörande av avtal eller åtgärder inför avtal.
  • Betalning: betalningsuppgifter lämnas direkt till Stripe eller den valda betalningsleverantören. Vi får uppgifter som behövs för att bekräfta och hantera betalningen, inte ditt fullständiga kortnummer eller kortets säkerhetskod. Rättslig grund: fullgörande av avtal.
  • Kundservice: kontaktuppgifter och de uppgifter du själv lämnar i e-post eller annan kontakt, inklusive ordernummer när det behövs. Vi använder dem för att besvara frågor, hantera reklamationer och följa upp ärenden. Rättslig grund: avtal när det gäller ett köp, annars vårt berättigade intresse av att ge kundservice.
  • Bokföring: köp- och betalningsunderlag som behövs för redovisning och skatt. Rättslig grund: rättslig förpliktelse.
  • Webbplats och säkerhet: tekniska uppgifter såsom IP-adress, webbläsarinformation, sidvisningar och prestandauppgifter kan behandlas för drift, felsökning, säkerhet och webbstatistik. Rättslig grund: vårt berättigade intresse av en säker och fungerande butik, när inte samtycke krävs.
  • Frivilliga utskick: om vi erbjuder nyhetsbrev eller erbjudanden som du väljer att prenumerera på använder vi din e-postadress med ditt samtycke. Du kan när som helst avsluta prenumerationen. Ordermeddelanden skickas för att hantera ditt köp, inte för att du har anmält dig till reklam.

Beställnings- och leveransuppgifter är nödvändiga för att vi ska kunna genomföra ett köp. Om du inte lämnar nödvändiga uppgifter kan vi inte ta emot eller leverera beställningen. Vi ber dig inte att lämna känsliga personuppgifter.

3. Vem får del av uppgifterna och hur överförs de?

Vi lämnar endast ut uppgifter i den omfattning som behövs för respektive ändamål. Uppgifter delas med följande mottagare:

  • Stripe och valda betalningsleverantörer (exempelvis Klarna): uppgifter skickas via betalningsleverantörens kassa och skyddade API-anslutningar (HTTPS). Stripe hanterar betalningar och betalningsbekräftelser. Klarna behandlar uppgifter när du väljer Klarna. Betalningsleverantörerna kan även behandla uppgifter för egna ändamål, till exempel bedrägerikontroll. Stripes integritetspolicy och Klarnas dataskyddsinformation.
  • Cloudflare: används för webbplatsrelaterade tjänster, statistik och orderadministration. Orderreferenser, kontakt- och leveransuppgifter samt orderstatus kan behandlas i vår orderlösning. Överföring sker via HTTPS och tjänsternas API:er. Cloudflares integritetspolicy.
  • Resend och e-postleverantörer: e-postadress och innehållet i order- eller kundservicemeddelanden behandlas för att leverera e-post. Ordermeddelanden skickas via ett skyddat API till Resend och vidare via e-post. Resends integritetspolicy.
  • Fraktföretag: mottagarens namn, leveransadress och vid behov kontaktuppgifter lämnas till den transportör som används, genom transportörens bokningssystem, frakthandlingar och adressetiketter, så att paketet kan levereras.
  • Bokföring och myndigheter: relevanta köpunderlag kan lämnas till redovisningsleverantörer och behöriga myndigheter via deras system eller annan lämplig kanal när det behövs för redovisning eller enligt lag.
  • Webbhotell och Google Fonts: tekniska anslutningsuppgifter kan behandlas när webbplatsen och externa typsnitt hämtas via HTTPS. Googles integritetspolicy.

Vi säljer inte dina personuppgifter.

4. Överföring utanför EU/EES

Våra tekniska leverantörer kan behandla uppgifter i andra länder, bland annat USA. När uppgifter överförs utanför EU/EES ska en giltig överföringsgrund enligt GDPR användas, till exempel ett beslut om adekvat skyddsnivå (EU–USA:s dataskyddsramverk för certifierade mottagare) eller EU-kommissionens standardavtalsklausuler.

Leverantörernas information om överföringsskydd finns bland annat i Stripes överföringsvillkor, Cloudflares standardavtalsklausuler och Resends personuppgiftsbiträdesvillkor. Kontakta oss om du vill veta vilka skyddsåtgärder som gäller för dina uppgifter eller få en kopia av relevanta villkor.

5. Hur skyddar vi dina uppgifter?

Webbutiken använder HTTPS för att skydda kommunikationen mellan din webbläsare och våra tjänster. Kortuppgifter matas in i betalningsleverantörens kassa och sparas inte i SweForms egen butikskod eller varukorg.

Orderadministrationen är avsedd för behörig personal och skyddas genom inloggning. Betalningsmeddelanden från Stripe kontrolleras med digital signatur innan orderhantering sker. Anslutningar mellan order-, betalnings- och e-posttjänster använder HTTPS och autentisering. Vi begränsar de uppgifter som delas till vad som behövs för tjänsten.

Ingen överföringsmetod kan garantera fullständig säkerhet. Kontakta oss om du misstänker att dina uppgifter har hanterats felaktigt.

6. Hur länge sparar vi uppgifterna?

Orderuppgifter sparas så länge de behövs för att genomföra köpet och hantera eventuella returer, reklamationer eller rättsliga anspråk. Räkenskapsinformation sparas enligt bokföringslagen, normalt till och med det sjunde året efter utgången av det kalenderår då räkenskapsåret avslutades.

Kundserviceuppgifter sparas så länge ärendet behöver hanteras och därefter om de behövs för att dokumentera ett köp eller ett anspråk. Uppgifter för frivilliga marknadsföringsutskick används tills du återkallar ditt samtycke eller utskicken upphör. Tekniska uppgifter sparas så länge de behövs för drift, statistik och säkerhet enligt respektive tjänsts lagringsvillkor. Uppgifter som inte längre behövs ska raderas eller anonymiseras, om inte lag kräver fortsatt lagring.

7. Kakor, varukorg och webbstatistik

Varukorgen använder webbläsarens lokala lagring och sessionslagring för att komma ihåg valda produkter och hantera övergången till kassan. Denna lagring används för butikens funktion. Du kan rensa den via webbläsarens inställningar; då kan innehållet i varukorgen försvinna.

Vi använder Cloudflare Web Analytics för att förstå hur webbplatsen används och hur snabbt den laddas. Den tjänsten använder inte kakor för denna mätning. Mer om Cloudflare Web Analytics. Betalningsleverantörens kassa kan använda egna kakor eller motsvarande teknik enligt leverantörens information.

8. Dina rättigheter

Du kan begära tillgång till dina personuppgifter, rättelse av felaktiga uppgifter och, när förutsättningarna är uppfyllda, radering, begränsning av behandling eller dataportabilitet. Du kan invända mot behandling som grundas på berättigat intresse och alltid invända mot direktmarknadsföring. Du kan återkalla ett samtycke utan att det påverkar tidigare laglig behandling.

SweForms fattar inte egna beslut med rättsliga eller liknande betydande följder för dig enbart genom automatiserad behandling. Betalningsleverantörer kan ha egna automatiserade risk- eller kreditbedömningar; se deras respektive integritetsinformation.

Mejla kontakt@sweforms.se för att utöva dina rättigheter. Du kan även lämna ett klagomål till Integritetsskyddsmyndigheten (IMY).

9. Ändringar och kontakt

Vi uppdaterar policyn när våra tjänster eller rutiner förändras. Har du några frågor om hur dina uppgifter hanteras är du alltid välkommen att kontakta oss på kontakt@sweforms.se.
